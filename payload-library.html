① Identify the context

先用 harmless marker 確認反射位置；分清 HTML text、Attribute、JavaScript、Template、Database 等 context。

② Compare a control

唔好只憑 200 OK 或 error；盡量比較 baseline 同 controlled variants，再睇 Browser／DB／Parser 實際效果。

③ Record evidence

保留 Request、Response、實際 State 或 Browser execution。測試字串本身唔代表漏洞存在。
