Quick reference · Avoid common mistakes

ffuf / Gobuster

Use small lists first. Distinguish wildcard responses from real endpoints. Fuzzing can still create high request volume even at low concurrency.

sqlmap

Prefer a saved Burp request and one parameter. Start with --level=1 --risk=1; automatic detection is not proof of business impact.

Nmap / CVE

Run safe-category NSE checks or correlate service versions with known CVEs via Vulners. External lookups may disclose version information; manually validate all matches.

Hydra

Only synthetic test credentials with a very short file and account-lockout permission. This tool can lock accounts even with one worker.

SSH Pivot

Local forwarding and SOCKS bind to 127.0.0.1. ProxyJump requires working SSH credentials and explicit network scope.

Wordlist check

Default paths are examples for Kali/SecLists. Run ls on the chosen wordlist first and substitute an installed file if needed.
